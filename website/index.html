  1. Start a team

    Open the CADSwarm workbench in FreeCAD and follow the guide. Name the project and pick a folder. That's the whole setup.

  2. Share the invite code

    Teammates paste one code to join. Each of them connects their own Claude Code or Codex in a click.

  3. Split the work

    A lead agent sets the shared sizes and hands out tasks. The other agents claim them and build their parts.

  4. Steer and export

    Message any agent from the panel, run a clash check, and save the result as STEP or STL.

Everyone's agents build at the same time,

on your own machines, in one shared model.

Bring your own agent.

Use the Claude Code or Codex subscription you already have. CADSwarm gives each one a set of CAD tools: make shapes, hold parts, read shared sizes, check clashes.

Hosted by one teammate.

The team server runs on the host's computer next to the model file. Your designs stay on your machines unless you choose to share them.

Guard rails on every change.

Each change runs as one undoable step. Agent scripts can build geometry but can't open, write or delete files on your computer. Files go through save_file, which never overwrites by accident.

Install in about five minutes.

Paste one line. It fetches CADSwarm, finds FreeCAD and opens it with the setup guide.

New here? The quickstart walks one team build end to end. Every button and every failure is in the guide.

PowerShell
> irm https://raw.githubusercontent.com/SachchitBalamurugan/cadswarm/main/install/quick-install.ps1 | iex

Or install by hand

  1. Install FreeCAD 1.0+

    Download it free from freecad.org. The default options are fine.

  2. Download CADSwarm

    On GitHub, click Code ▸ Download ZIP and unzip it anywhere.

  3. Run the installer

    Double-click Install CadSwarm.cmd in the unzipped folder.

  4. Follow the guide in FreeCAD

    Start a new team project, or paste a teammate's invite code to join one.

Terminal
$ curl -fsSL https://raw.githubusercontent.com/SachchitBalamurugan/cadswarm/main/install/quick-install.sh | bash

Use the official FreeCAD AppImage. The snap, Flatpak and distro packages have no Python of their own, so with them you can join a team but not start one or connect an AI helper. The installer offers to fetch the official FreeCAD for you (about 3 GB unpacked).

Or install by hand

  1. Install FreeCAD 1.0+

    Get the AppImage from freecad.org, or let the installer download it.

  2. Download CADSwarm

    On GitHub, click Code ▸ Download ZIP and unzip it anywhere.

  3. Run the installer

    Run bash "Install CadSwarm.sh", or right-click it and choose Run as a Program.

  4. Follow the guide in FreeCAD

    Start a new team project, or paste a teammate's invite code to join one.

Installer options go after | bash -s --: --yes (no questions), --get-freecad, --no-shortcut, --no-launch. Set CADSWARM_FREECAD to use a specific FreeCAD.

You'll also need an AI helper

Install one and sign in once in a terminal. CADSwarm starts it for you after that.

  • Claude Code · run claude
  • Codex · run codex
  • Factory Droid · run droid

What gets downloaded

About 70 MB of helper software into CADSwarm's app folder. Whoever starts a team gets about 50 MB more: the team server and SpacetimeDB, each checked by SHA-256. Nothing is installed into FreeCAD itself.

Next time
